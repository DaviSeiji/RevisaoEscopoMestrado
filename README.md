# Revisão de Escopo - Mestrado

Questões:

RQ1) Aplicação Industrial: Qual o setor explorado? (Ex: Automobilístico, Petróleo, Química, Têxtil, etc.).

RQ2) Problema Industrial: Qual a finalidade da aplicação? (Ex: Manutenção Prescritiva, RUL - Vida Útil Restante, Detecção de Falhas, Controle de Qualidade). 

RQ3) Suporte à Decisão: Como a técnica auxilia na decisão? (Ex: Sugere uma ação corretiva, automatiza um ajuste de parâmetro, emite alerta com justificativa).

RQ4) Origem dos Datasets: Os dados utilizados são públicos (benchmarks como Tennessee Eastman ou NASA RUL), privados/proprietários ou simulados? (Coloque o link do dataset caso exista).

RQ5) Tipos de Dados: Quais tipos de dados são mais recorrentes? (Ex: Séries temporais de sensores, dados tabulares, imagens/vídeos, fusão de dados multimodais).

RQ6) Local de Processamento (Arquitetura): Onde o modelo é executado e quais os desafios relatados? (Edge Computing, Cloud Computing ou sistemas híbridos).

RQ7) Algoritmos de Deep Learning: Quais arquiteturas são utilizadas? (Ex: CNN, LSTM, GRU, Autoencoders, Transformers, arquiteturas híbridas).

RQ8) Técnica de XAI: Qual método de explicabilidade foi incorporado? (Ex: SHAP, LIME, Grad-CAM, Mapas de Atenção, Explicações Contrafatuais, Ontologias).

RQ9) Escopo da Explicação: A técnica foca em explicações Locais (explicar uma predição específica) ou Globais (explicar o comportamento geral do modelo)?

RQ10) Métricas de Avaliação: Quais métricas medem o sucesso? (Acurácia, F1-Score, Precisão, Latência de resposta, Tempo de processamento).

RQ11) Desafios e Lacunas: Quais as principais dificuldades reportadas pelos autores? (Ex: Escassez de dados rotulados, falta de confiança dos operadores, custo computacional, dificuldade em validar as explicações).
